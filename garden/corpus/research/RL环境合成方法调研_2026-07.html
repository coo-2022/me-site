强化学习中的环境合成:方法调研

调研日期:2026-07-06 · 上游:[垂域数据清洗与合成调研_2026-07]· [AReaL_2.0_自演进能力解读_2026-07]

0. 结论先行

  1. 瓶颈已从数据转移到环境:RLVR 时代,谁有更多”可交互、可验证、够多样”的环境,谁就能继续 scale RL。2025–2026 年环境合成论文密集爆发(EnvScaler/EnvFactory/ScaleEnv/AWM/AgentScaler),直接原因是手工环境(WebArena、τ-bench 类)只有几十个,喂不饱 RL。
  2. 六条技术路线并存:经典 UED 自动课程、程序化环境合成(LLM 写环境代码)、真实软件改造(SWE-Gym 系)、LLM 模拟环境(Kimi K2 路线)、自出题 self-play(AZR)、世界模型(Genie 3)。当前生产主流是程序化合成 + LLM 模拟的混合。
  3. 环境合成的命门是可验证性:环境可以假(模拟),但 reward 必须真(状态校验/单测/执行结果)。所有成功方案都在这一点上做了硬设计。
  4. 环境合成本质上是把”衡量标准”做成了可执行程序——这是三元组里最难的一环被工程化的过程。

1. 为什么环境成了瓶颈

RL 训练消耗的不是样本而是交互。预训练吃静态文本,RLVR 吃”(任务, 环境, 验证器)“三元组:

  • 手工环境太少:高质量 agent 环境(可执行、有验证器)全球范围内只有百级;
  • 真实 API 太贵且不可控:限流、不可复位、副作用真实发生;
  • 纯 LLM 模拟太飘:幻觉响应会被策略模型当成漏洞利用(reward hacking 的温床);
  • 合成任务太假:轨迹常是”过度规定”的指令序列,不像真实人类意图(EnvFactory 对现状的批评)。

环境合成要同时解决:规模(千级环境)、保真(响应符合工具语义)、可验证(reward 可信)、多样(防过拟合)。

2. 六条技术路线

路线 A:经典 UED / 自动课程(LLM 之前的理论底座)

机制:把”环境该长什么样”本身变成优化问题。

方法机制关键思想
POET (2019)环境与智能体种群共进化开放式生成越来越难的环境-解对
PAIRED (2020)教师生成环境,以 protagonist/antagonist 的**表现差(regret)**为教师奖励minimax regret:出”刚好够难”的题
ACCEL (2022)对高 regret 环境做小幅变异编辑进化式课程,始终停在能力前沿

(POET arXiv:1901.01753 · ACCEL arXiv:2203.01302)

这些方法当年只在网格世界/游戏关卡上验证,但regret 驱动的难度课程思想被 LLM 时代全盘继承(见 §3.2)。

路线 B:程序化环境合成——LLM 写环境代码(当前最热)

机制:不是让 LLM 在推理时”扮演”环境,而是让 LLM 生成环境的代码(工具 schema + 状态机 + 数据库 + 校验逻辑),环境本身确定性执行。

工作规模要点
AgentScaler(通义)—“环境规模化”路线的代表:模拟工具环境采轨迹,用可验证的环境状态变化过滤数据——reward 看数据库状态是否正确变更,不看模型自述
EnvScaler191 环境 / ~7K 场景程序化合成工具交互环境,多轮多工具基准显著提升
EnvFactory—全自动:环境合成 + 任务合成 + 鲁棒 RL 一条龙,针对”轨迹不像真实意图”问题重新设计任务生成
ScaleEnv—从零合成环境,目标是通用工具使用泛化
Agent World Model (AWM)1,000 个代码驱动环境(带数据库)环境即代码 + 状态即数据库,目前公开规模最大

共同配方:环境 = 代码(确定性)+ 状态 = 数据库(可断言)+ reward = 状态断言(可验证)。LLM 只负责离线造环境,在线交互全是确定性执行——把”保真”与”规模”解耦。

路线 C:真实软件改造——把现实世界变成环境

机制:真实代码库天然自带验证器(单元测试),把它包装成可复位的执行环境。

工作规模要点
SWE-Gym2,438 个真实 Python 任务真实 PR + 可执行运行时 + 专家校验测试;另放出 64,689 条无环境原始 issue 供后续合成
SWE-smith50K 实例 / 128 仓库反向造题:往真实代码库注入 bug(改坏使测试失败),执行验证候选,规模比前人大一个数量级
R2E-Gym / CUA-Gym—同思路扩展到通用 repo 与计算机操作(GUI)任务

SWE-smith 的洞察值得单独记:执行验证既能判解,也能反向发现”值得出的题”(哪些改动会破坏测试 = 哪些地方是好考点)。这是”验证器反哺出题器”的典型。

路线 D:LLM 模拟环境——model-as-environment(生产已用)

机制:用 LLM 实时扮演工具响应/用户行为,换取无限规模与零成本。

  • Kimi K2:数千个真实 MCP 工具 + 合成工具组成工具库,LLM 模拟器生成多轮工具调用的 observation,大规模合成 agent 轨迹后做联合 RL(K2 技术报告)。生产验证最强的案例。
  • 用户模拟器:τ²-bench 式的 LLM 扮演用户,提供多轮对话压力;AReaL-SEA 的合成数据引擎同样内含用户模拟。
  • 用推理模型当环境:arXiv:2511.01824 显示强推理模型模拟环境响应的一致性显著优于普通 LLM。

风险与对策:模拟器幻觉 = 策略可利用的漏洞。对策是混合架构——响应可以由 LLM 生成,但关键状态转移和最终 reward 必须落在确定性代码/数据库上(路线 B 与 D 融合,AgentScaler 的状态校验即此)。

路线 E:自出题 self-play——环境即验证器

机制:模型自己提出任务 + 解任务,靠一个天然验证器闭环,零外部数据。

  • Absolute Zero Reasoner(arXiv:2505.03335):以 Python 执行器同时充当任务构造、校验、验证三角色;按演绎/溯因/归纳三类出码题;proposer 的 reward 是任务的”可学习性”(太难太易都不给分——regret 思想的 LLM 版)。零数据训练,数学+代码平均分超过用数万人工标注样本训练的模型。
  • reasoning-gym 类:程序化任务生成器(数学/逻辑/棋类),难度参数化,无限出题,答案程序可判。

局限:只覆盖”存在天然验证器”的域(代码/数学/游戏);出题分布可能漂移,需要多样性正则。

路线 F:世界模型——用生成模型造世界

机制:视频世界模型实时生成可交互环境(Genie 3:文本提示 → 720p/24fps 可导航世界,一致性维持数分钟)。

  • 2025-11 DeepMind 展示 SIMA 2 在 Genie 3 生成的世界里自我提升,无需新的人类示例——“AI 在另一个 AI 发明的世界里训练”的首个明确证据(DeepMind, TechTimes)。
  • 主战场是具身智能/机器人(物理世界交互太贵),对 LLM agent 暂非主路线。评级:前沿,盯趋势即可。

3. 跨路线的四个关键设计问题

3.1 可验证性(最重要)

Reward 信号的可信来源排序:程序执行/单测 > 数据库状态断言 > 规则校验 > LLM judge。所有量产方案的共性:把 reward 尽量往左移。LLM judge 只能当辅助闸,不能当主 reward——策略模型会学会骗 judge。

3.2 难度课程

UED 的 regret 思想全面回归:AZR 的”可学习性 reward”、各环境合成工作的难度参数化,本质都是出”当前模型 50% 左右能做对”的题——太易无梯度,太难全零奖。实操上按 pass rate 动态分桶采样即可得到 80% 的收益。

3.3 多样性

环境同质化 → 策略过拟合合成分布。手段:工具库去重(schema 级)、场景 persona 化(与 垂域数据清洗与合成调研_2026-07 的 Persona Hub 同源)、跨域混采;AWM 用 1,000 个异构环境硬堆多样性。

3.4 防 reward hacking

环境是合成的,漏洞也是合成的。已知教训:模拟器响应含糊 → 模型学会套话过关;测试覆盖不全 → 模型学会”改测试不改代码”。对策:状态断言而非输出匹配、隐藏测试集、轨迹抽检 + 对抗性环境更新(环境也要迭代,类似 PAIRED 的教师)。

4. 垂域落地配方(接上一篇的工单/文档/规范)

上一篇解决”存量数据 → SFT 集”,环境合成解决”SFT 之后 → RL 继续提升”:

垂域资产合成环境方案路线
工单系统工单处理环境:模拟用户(LLM,路线 D)+ 内部工具沙盒(查订单/改配置,路线 B 代码化)+ reward = 工单终态字段断言B+D 混合
规范制度判定环境:条款编译成校验函数,agent 的处理流程逐步过规则引擎B(纯确定性)
内部系统 API照 AgentScaler:schema 导出 → LLM 生成 mock 实现 + 种子数据库 → 状态变化校验B
代码仓库SWE-smith 式 bug 注入,单测当验证器C

起步顺序建议:先做规范判定环境(全确定性、最不会翻车)→ 再上工单环境(引入用户模拟)→ 最后 API 沙盒(工程量最大)。

5. 判断

  1. “环境即代码、状态即数据库、reward 即断言”是 2026 年的收敛答案——它把 LLM 的创造力(离线造环境)和确定性执行(在线保真)干净地分开了。
  2. 验证器是新的数据飞轮:SWE-smith 证明验证器可以反向出题,AZR 证明验证器可以支撑零数据自演进——环境合成的竞争本质是验证器覆盖率的竞争。
  3. 路线正在合流:程序化合成(B)提供骨架,LLM 模拟(D)填充血肉,regret 课程(A)调度难度,self-play(E)在有天然验证器的域内自转。终局形态大概率是四者的组合系统。
  4. 用三元组看:环境合成 = 把衡量标准做成可执行、可复位、可规模化的程序。数据化(轨迹)和元能力(策略优化)早就有了,RL scale 卡在衡量标准的供给上——这也解释了为什么”环境公司”(出售 RL 环境)成了 2026 年的新物种。
