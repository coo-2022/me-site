一、核心结论

当前 RL 的热点 ≈ 「用 RL 把大模型练得更会推理、更像智能体」。 最热关键词:RLVR（可验证奖励）、后 GRPO 算法、过程奖励/奖励 hacking、Agentic RL、多模态 VLA，背后是异步训练系统与高效推理。 演进主线:RLHF（人工反馈）→ RLVR（可验证）→ 无监督/内在奖励 + 从环境自学。

学术界 vs 一线实验室的分工:

  • 学术界（arXiv/知乎）:打磨 RLVR 算法与推理能力。
  • 一线实验室（Twitter）:已往前两步——押注异步万亿参数 RL 系统 + Agent 从环境自学 + 优化 agent harness。

六、深挖：prime-rl & Prime Intellect

prime-rl 0.6.0 thread 全文要点（@samsja19）

训 1T 参数 MoE，单步 <5 分钟，1k 步约 3 天。0.6.0 改动:

  • 推理:wide-ep、fp8 推理、llm-d router、mooncake、KV cache CPU offload
  • 训练:fsdp2、deep-ep 专家并行、dsa cp、fp8 训练、router replay
  • agentic rollout:重写 rollout 编排器核心提升可扩展性
  • 支持 GLM-5、Kimi、Nemotron…
  • 开源，但针对自家 RL 基建/算力层端到端优化

社区 insight:

  • “真正的解锁是速度不是规模——快 10x 迭代在反馈循环里就是碾压优势”
  • “5 分钟单步不重要，一个节点挂了后 fsdp2 多快恢复才关键”（分布式容错才是硬骨头）

prime-rl repo（PrimeIntellect-ai/prime-rl）

定位:Async RL Training at Scale。 差异化:

  • 全异步 RL——高吞吐 agentic 训练（核心卖点）
  • 训 1T+ MoE / 1000+ GPU:FSDP2 + vLLM，FP8 推理、PD 解耦、EP/CP 并行
  • 原生接 verifiers Environments Hub，内置 SWE / agentic 环境
  • 端到端后训练:SFT + RL + evals；Slurm/K8s 多机；VLM 支持（Qwen3-VL）
  • 一行 SLURM 部署前沿模型（GLM-5 FP8 + llm-d router + Mooncake KV offload）

七、prime-rl vs verl

维度prime-rl（Prime Intellect）verl（字节 Seed 团队）
出身去中心化 AI 创业公司，2024字节跳动 Seed，HybridFlow 论文开源版
核心架构全异步 + PD 解耦:推理与训练分离、各自连续跑Hybrid-Controller / 3D-HybridEngine:训练与生成在同一批 GPU 上 reshard 切换
设计哲学为异构/分布式/长 rollout 的 agentic 训练优化为紧凑集群上的极致吞吐优化（消除 train↔gen 显存冗余）
agentic 支持一等公民:原生 Environments Hub、SWE/agentic 环境后补:2026/05 才出 uni-agent
成熟度/生态新，绑自家算力层，前沿规模秀肌肉业界事实标准，社区大、生产验证充分
算法GRPO/PPO + 自家优化GRPO/PPO 几行代码搭，算法灵活性强
共同点FSDP、vLLM、FP8、MoE、1T 级、HF 模型同

选型直觉

  • verl:字节出品「灵活 + 高吞吐」生产级 RL 库，靠 HybridEngine 在同集群 train/gen 切换榨满利用率，算法灵活、生态最成熟 → 有稳定大集群做 RLHF/推理训练。
  • prime-rl:Prime Intellect「全异步 + 解耦」框架，推理训练拆开异步跑，天生适配 agentic（长 rollout、多环境交互）和去中心化/异构算力 → 做 agentic RL / 长交互 rollout / 跑在分散弹性算力上。

两者架构哲学正好相反（同集群 reshard vs 异步解耦），是当前 RL 系统层最值得关注的分叉。

八、值得持续跟踪的信号

  1. Prime Intellect 的 prime-rl — 开源 agentic RL 基建，异步万亿参数训练。
  2. GLM-5.2 放弃 GRPO — 头部模型对算法范式的重新选择，可能带动「后 GRPO」浪潮。
  3. 「从环境自学，超越 reward」 — RL 与预训练融合的新范式（samsja19、yinglun122）。
  4. 优化 agent harness 本身 — HarnessBridge 等，不止优化策略。
  5. 无监督 / 内在奖励 RL — 摆脱人工标注奖励的下一焦点（知乎风向）。
